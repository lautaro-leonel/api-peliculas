# API de Películas (Sci-Fi) – FastAPI

API REST desarrollada en Python con **FastAPI** para consultar información de películas de ciencia ficción.
Proyecto personal para practicar backend, diseño de endpoints, filtros y conexión con base de datos.

## Tecnologías
- Python
- FastAPI
- SQLAlchemy
- SQLite
- JSON

## Funcionalidades
- Listado de películas
- Búsqueda por ID
- Filtros por: año, subgénero, director, rating_min, rating_max
- Ordenamiento por: anio o rating (asc/desc)
- Paginación: page y size
